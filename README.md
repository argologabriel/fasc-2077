# 🌐 FASC 2077

**FASC 2077** é um projeto conceitual que simula uma edição futurista do Festival de Artes de São Cristóvão, ambientada no ano de 2077. Esta versão atípica do evento propõe imaginar como seria o festival no futuro, com atrações inusitadas e nunca antes cogitadas, explorando uma visão criativa e tecnológica das artes e da cultura.

## 🚀 Objetivos

- Simular uma edição do FASC no ano de 2077   
- Permitir o cadastro de artistas e seus dados de apresentação  
- Permitir o cadastro de shows com informações como data, local e artistas participantes  
- Exibir a programação completa do festival de forma visual e organizada 
- Estimular a criatividade com base em um cenário artístico-futurista
